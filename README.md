# 印刷车间安全评估

这是一个 Go 1.24 单模块命令行项目，用于登记机台、油墨区、纸库和成品区的风险分值与本地 JSON 证据，并发布包含企业档案、高风险项、整改清单和报告时间线的评估报告。高风险阈值为 70 分（含 70 分）。

## 运行入口

从模块根目录执行：

```sh
go run ./cmd/printshop-safety -input examples/assessment.json
```

命令读取评估文件及其中引用的本地证据文件，将完整报告写入标准输出。证据文件格式如下：

```json
{"summary":"现场证据摘要","source":"巡检记录编号"}
```

## 业务测试

从模块根目录执行完整命令：

```sh
go test -count=1 ./...
```

项目仅使用 Go 标准库，可在 `CGO_ENABLED=0` 环境中构建。
